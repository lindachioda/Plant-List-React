# 🌱 Plant List React

Plant List React is a practice project developed to learn and explore form handling in React. The application allows users to add new plants to an existing list by filling out a form. Each submission dynamically creates a new plant card displaying the plant's information.
This project focuses on managing form inputs, handling user interactions, and dynamically rendering lists of components using React.

* Add new plants through a form.
* Dynamically generate plant cards.
* Display plant information, including name, description, and image.
* Track whether a plant is already in the collection.
* Responsive layout for different screen sizes.

## 🎯 Goals

* Understanding how forms work in React.
* Managing component state with `useState`.
* Handling input changes and form submissions.
* Passing data between components using props.
* Rendering lists dynamically with `map()`.
* Applying responsive styling with Tailwind CSS.
